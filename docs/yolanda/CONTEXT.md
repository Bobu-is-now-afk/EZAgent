# 人工复核与审批术语

本术语表只界定 YOLANDA 模块中的业务含义，不改变团队其他模块的术语或架构。

## Language

**任务假设（Task assumption）**：系统对用户本次票据处理范围或规则的建议解释。关键假设只有经用户确认后才能作为批准依据。

**原始证据（Evidence）**：支持一个业务事实的原始单据内容及其来源位置。人工更正不能覆盖原始证据。

**识别建议（Extracted suggestion）**：系统从原始证据中得出的候选字段值。它不等于已经确认的事实。

**人工更正（Correction）**：用户对识别建议提交的有记录的修正。更正值与原建议并存。

**匹配关系（Match）**：本次票据记录与指定台账记录之间经规则或人工确认的对应关系。本版只支持一对一匹配。

**阻塞项（Blocker）**：使当前批次不能批准的未解决问题。经理身份本身不能消除阻塞。

**排除（Exclusion）**：有理由地将记录移出本次处理范围，同时保留证据和待办状态。排除不代表已处理成功。

**结果版本（Revision）**：一次可被区分的完整业务内容状态。影响结果的有效变更产生新版本。

**批准（Approval）**：经理对一个确定结果版本的确认，范围仅限本模块规定的导出与人工后续使用。批准不等于付款、发送授权或专业合规判断。

**批准快照（Approval snapshot）**：批准时确认的参数、结果、草稿和排除项的固定副本。后续变更不能悄悄改变它。

**有效批准（Current approval）**：仍对应当前结果且未被修改或撤销失效的批准。历史批准不自动代表当前版本有效。

**工作副本（Working copy）**：保存复核进度、供稍后继续工作的未批准材料。恢复工作副本不继承可信审批权限。

**消息草稿（Message draft）**：供用户检查并在外部工具自行使用的文本。生成、批准、复制或下载均不代表已经发送。

## 工作流配置器补充术语

**工作流配置（Workflow configuration）**：用户确认的任务目标、输入、处理规则、待确认问题、输出和所需执行能力。它是摘要、提示词、备份和交接数据的唯一来源。

**配置确认（Configuration confirmation）**：用户确认当前 revision 的规则完整且含义正确。配置变化会使对应确认失效；它不代表工作已经执行。

**执行能力状态（Execution capability status）**：执行模块对当前配置所需能力的独立判断。配置完整不等于可以试跑。

**本机工作流（Local workflow）**：保存到当前浏览器 IndexedDB 的配置及版本记录。它没有自动同步到工具库、云端或其他浏览器。
